# Country dataset pipeline

`data/countries.json` is generated by `build_countries.py`. Network sources are cached under `data/raw/` and never re-fetched unless you delete the file. Stats derived from factbook are computed fresh on every run from the cached files — no per-stat duplication.

```
pip install -r data/requirements.txt
python data/build_countries.py
```

## Layout

```
data/
├── build_countries.py
├── countries.json          # generated output
└── raw/                    # cached network sources (gitignored)
    ├── base.json           # REST Countries — UN members
    ├── gdp.json            # World Bank GDP per capita
    ├── passport.json       # passportindex.org rank
    └── factbook/
        ├── nl.json         # one cached CIA Factbook entry per country
        ├── us.json         # (filenames are CIA / GEC codes, not ISO2)
        └── ...
```

| Cache | Source | Field(s) it provides |
|---|---|---|
| `raw/base.json`          | [REST Countries](https://restcountries.com)                            | name, code, capital, continent, population, area, landlocked, borders |
| `raw/gdp.json`           | [World Bank](https://api.worldbank.org/v2/) — `NY.GDP.PCAP.CD`         | gdp_per_capita_usd |
| `raw/passport.json`      | [passportindex.org/byRank.php](https://www.passportindex.org/byRank.php) | passport_rank |
| `raw/factbook/<cia>.json` | [factbook/factbook.json](https://github.com/factbook/factbook.json)    | coastline, life expectancy, median age, population growth, obesity, alcohol, unemployment, highest point, internet users |

## Workflows

- **Refresh a fetched source** → `rm data/raw/<file> && python data/build_countries.py`
- **Refresh one country's factbook entry** → `rm data/raw/factbook/<cia>.json && rerun`
- **Refresh all factbook stats** → just re-run; extractors execute fresh on every run from the cached files (no network).
- **Refresh everything** → `rm -r data/raw && rerun`

## Manual fixes

`raw/base.json` and `raw/factbook/<cia>.json` are plain JSON. Edit by hand and re-run; your edit sticks because the file already exists. Edits to a factbook file flow into `countries.json` immediately because the extractors run on every build.

## Add a new factbook stat

See [FACTBOOK_FIELDS.md](FACTBOOK_FIELDS.md) for the full list of available paths in a factbook entry. Three small steps:

1. **Pipeline** (`data/build_countries.py`) — write an extractor and register it:
   ```python
   def extract_birth_rate(fb):
       return _first_number(_text(fb, "People and Society", "Birth rate"))

   FACTBOOK_STATS = [
       …existing entries…,
       ("birth_rate_per_1000", extract_birth_rate),
   ]
   ```
   Helpers available: `_text(fb, *keys)`, `_first_number(text)`, `_walk(d, *keys)`, `_latest_year_text(node, prefix)`.

2. **Game logic** (`higher-lower/app.js`) — add a `STAT_META` entry. Pick a `unit` matching an existing branch in `formatValue()` (`rank`, `usd`, `km`, `compact`, `km2c`, `years`, `pct`, `litres`, `m`) or add a new one.

3. **Game UI** (`higher-lower/index.html`) — add an `<option>` to the stat picker.

Then run `python data/build_countries.py` once. No network calls — extractors read from the existing factbook cache.

## Why CIA codes?

[factbook/factbook.json](https://github.com/factbook/factbook.json) names files by **CIA Factbook two-letter codes** (a.k.a. GEC / FIPS 10-4), not ISO 3166-1 alpha-2. So Algeria is `ag` (not `dz`), Australia is `as` (not `au`), Burma is `bm` (not `mm`). The pipeline keeps an `ISO2_TO_CIA` map at the top of `build_countries.py` covering all 193 UN members.
