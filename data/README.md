# Country dataset pipeline

`data/countries.json` is generated by `build_countries.py` from per-source shards under `data/raw/`. The shards are **committed** to the repo, so cloning + running the script regenerates `countries.json` instantly with no network calls.

```
pip install -r data/requirements.txt
python data/build_countries.py
```

## How it works

Three independent sources, plus one shared cache for factbook (which feeds many stats):

| Shard | Source | Field(s) it provides |
|---|---|---|
| `raw/base.json`     | [REST Countries](https://restcountries.com)                                 | name, code, capital, continent, population, area, landlocked, borders |
| `raw/gdp.json`      | [World Bank](https://api.worldbank.org/v2/) — `NY.GDP.PCAP.CD`              | gdp_per_capita_usd |
| `raw/passport.json` | [passportindex.org/byRank.php](https://www.passportindex.org/byRank.php)    | passport_rank |
| `raw/factbook/{cca2}.json` | [factbook/factbook.json](https://github.com/factbook/factbook.json) | one cached file per country, feeds the stats below |

Stats derived from the factbook cache (each gets its own shard so a single one can be refreshed without re-fetching the rest):

| Shard | Field |
|---|---|
| `raw/coastline.json`         | coastline_km |
| `raw/life_expectancy.json`   | life_expectancy_years |
| `raw/median_age.json`        | median_age_years |
| `raw/population_growth.json` | population_growth_pct |
| `raw/obesity_rate.json`      | obesity_pct |
| `raw/alcohol_per_capita.json`| alcohol_l_per_year |
| `raw/unemployment_rate.json` | unemployment_pct |
| `raw/highest_point.json`     | highest_point_m |
| `raw/internet_users.json`    | internet_users_pct |

`load_or_build(path, fn)` reads the shard if it exists, otherwise calls the builder and writes it.

## Workflows

- **Refresh one stat** → `rm data/raw/<stat>.json && python data/build_countries.py`
- **Refresh all factbook stats but keep the cached country files** → `rm data/raw/coastline.json data/raw/life_expectancy.json …`
- **Re-fetch a country's factbook entry** → `rm data/raw/factbook/<cca2>.json data/raw/<stat>.json`
- **Refresh everything** → `rm -r data/raw && python data/build_countries.py`

## Manual fixes

Shards are plain JSON. If a value is wrong, edit the shard by hand and re-run; your edit sticks because the shard already exists. Same for `raw/factbook/<cca2>.json` — fix one country's cached entry, then delete the dependent stat shards to regenerate them from your fix.

## Add a new factbook stat

Three steps:

1. **Pipeline** (`data/build_countries.py`) — write a small extractor and register it:
   ```python
   def extract_birth_rate(fb):
       return _first_number(_text(fb, "People and Society", "Birth rate"))

   FACTBOOK_STATS = [
       …existing entries…,
       ("birth_rate_per_1000", "birth_rate.json", extract_birth_rate),
   ]
   ```
   The helpers `_text(fb, *keys)`, `_first_number(text)`, and `_latest_year_text(node, prefix)` cover most cases.

2. **Game logic** (`higher-lower/app.js`) — add a `STAT_META` entry. Pick a `unit` that matches an existing branch in `formatValue()` or add a new one (units already supported: `rank`, `usd`, `km`, `compact`, `km2c`, `years`, `pct`, `litres`, `m`).

3. **Game UI** (`higher-lower/index.html`) — add an `<option>` to the stat picker.

Then run `python data/build_countries.py` once to populate the new shard.
